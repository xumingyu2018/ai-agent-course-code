# 企业级知识库项目：全文检索管道

文档发布后，会给 RabbitMQ 发消息

然后有三条消费者管道：

- RAG：分块 → 向量化 → ES kh_chunk（语义检索）
- Search：文档快照 → ES kh_document（关键词检索）
- KG：分块 → 抽实体关系 → Neo4j（图谱关联查询）

## 总结

这节我们跑通了发布后的另一条管道：全文检索表的存储

现在 publish 之后，会走两条管道：

- 分块 → 向量化 → ES kh_chunk
- 文档快照 → ES kh_document

并且也做了文档删除时的同步处理。
